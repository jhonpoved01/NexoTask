# Documentación del proyecto

La documentación se organiza por propósito:

- `00-entrega-academica/`: acuerdos, evidencias e informes de entrega.
- `01-guia-sistema/`: manuales de uso funcional para usuarios.
- `02-arquitectura/`: estructura técnica y separación de aplicaciones.
- `03-migracion-vite/`: uso de Vite y proceso de migración del frontend.
- `04-git-github/`: Gitflow, ramas, Issues, Pull Requests y Milestones.
- `05-base-datos/`: preparación y decisiones futuras sobre MySQL.
- `06-formatos-maestros/`: copias documentales de plantillas y formatos.

Las plantillas que GitHub utiliza automáticamente permanecen en `.github/`.
