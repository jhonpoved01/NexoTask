# Base de datos

Esta carpeta documentará la futura migración desde JSON Server hacia MySQL,
incluyendo el modelo de datos, decisiones de diseño y proceso de migraciones.

Los archivos ejecutables de preparación se mantienen en la carpeta raíz
`database/`:

- `database/schema.sql`
- `database/seed.sql`
- `database/migrations/`

Actualmente estos archivos son marcadores de preparación y todavía no definen
un modelo SQL completo.
